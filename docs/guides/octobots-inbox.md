# Octobot's Inbox 🐙

On the road the thought arrives on the phone, not the laptop. Create a Telegram bot with @BotFather, put its token and your own chat ID into ⚙ Edit Settings… (`telegramBotToken`, `telegramChatId`; only that chat is accepted), and send it text, links or photos. **🐙 Check Octobot's Inbox…** fetches what is waiting and lets you attach each item to a day: text lands in the tale (a detected link can become a Weblink), photos go into the day's backpack. Blank settings = feature off. Nobody in the family needs to install anything new. Design notes: [docs/68_mobile_inbox.md](../68_mobile_inbox.md).
